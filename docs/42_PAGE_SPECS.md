# 核心页面规格

## Project Overview
Header：org/project、visibility、main frozen、star/watch。Body：Purpose、Key Questions、Key Findings、Active Paths、Needs Attention、Latest Release、Dependency Alerts、Recent Activity。

## Research Page
左侧 outline/question tree，中间 Research Map，右侧 selected node detail。支持 By Question/By Finding。Graph nodes 可键盘选择；有 list fallback。

## Scientific Object Detail
Header：type/id/version/status。主体：statement/metadata；关系；Provenance；Evidence；History；Files（只读）；Contribution。Object mutation action 主要显示 “Work with Agent”，治理 action 依据权限。

## PR
Summary、RSG Diff、Scientific Review、Integrity Review、Conflicts、Files Diff、Discussion、Checks、Merge governance。

## Release
Manifest summary、object counts、Findings、dependencies、policy/schema pins、hash、download/export。

## Asset Page
PID/version、type、origin、rights、creators、metadata、dependencies、lineage、used/derived public links、versions、network events。

## Knowledge Network Page
Statement/version、origin assessment、origin evidence、external reviewed/unreviewed evidence、competing objects、network state、references、fork/validate actions。

## Search Answer
Query、answer、conditions/comparison、limitations/conflicts、Evidence Map、sources、underlying results、Start Project。

## Research Profile
Affiliations、public contribution dimensions、accepted/released/reused/reproduced evidence、assets/projects、confidential verified contribution summaries。
