# 产品分析指标（不用于科研声誉评分）

V1 只收集最小运营指标：Project 创建/活跃、branch→PR conversion、PR cycle、release/asset publish、asset reference/fork、external contribution acceptance、search→project conversion、open contribution completion、dependency alerts。

禁止用隐私数据做未告知分析；不把科研内容送第三方 analytics SaaS。优先 self-hosted/内部 event aggregation。
