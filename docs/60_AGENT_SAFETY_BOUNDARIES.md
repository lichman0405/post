# Agent Safety / Autonomy Boundaries

Claude Code-style agent 的“自主”只指工程执行与代表用户做低风险科研状态操作，不代表可以自行做科学/治理决策。

必须 human-governed：merge accepted main、private→public、publish network object/asset、rights holder change、scientific conflict final resolution、credit dispute resolution。

Agent 可自动：读取上下文、创建用户授权 branch、解析/建议 metadata、建立高置信 provenance proposal、运行 validation、准备 PR、解释 diff、建议 reviewer/role。

所有自动推断应保留 confidence/source，涉及身份等价、因果、visibility 时必须转确认。
