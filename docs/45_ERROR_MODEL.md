# Error Model

核心 error code 示例：

- AUTH_UNAUTHENTICATED / AUTH_FORBIDDEN
- PROJECT_PRIVATE / OBJECT_NOT_VISIBLE
- MAIN_FROZEN_DIRECT_WRITE_FORBIDDEN
- BRANCH_STATE_CONFLICT
- EXPECTED_VERSION_MISMATCH
- RSG_VALIDATION_FAILED
- SCHEMA_VALIDATION_FAILED
- PROVENANCE_INCOMPLETE
- SCIENTIFIC_CONFLICT_REQUIRES_HUMAN
- PRIVATE_TO_PUBLIC_REQUIRES_APPROVAL
- RIGHTS_POLICY_BLOCKS_ACTION
- RELEASE_IMMUTABLE
- ASSET_VERSION_IMMUTABLE
- OBJECT_HISTORY_DELETE_FORBIDDEN
- DEPENDENCY_UNRESOLVED
- BLOB_NOT_ATTACHED / BLOB_INTEGRITY_FAILED
- GIT_RSG_DRIFT
- IDEMPOTENCY_CONFLICT

错误信息告诉用户下一步，不泄漏 private entity existence 或内部 stack。
