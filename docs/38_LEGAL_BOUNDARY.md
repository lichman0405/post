# 产品与法务边界

本文件不是法律意见。

平台负责结构化记录和执行：visibility、usage declarations、standard license id、custom agreement reference、required approvals、rights holder/custodian/maintainer、audit。

平台不负责替用户判断：专利有效性、合同解释、司法管辖、收益分配、商业秘密法律构成、数据权属争议的法律结论。

UI 必须避免把机器字段表述成“法律保证”。Custom Agreement 可以上传/引用并关联 policy，但业务引擎只执行明确编码的审批/访问规则。
